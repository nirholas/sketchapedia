# Getting started with sketchapedia

Sketchapedia — Model-as-a-Renderer SDK: generative pixel layer with an invisible semantic DOM overlay.

## Install

```bash
git clone https://github.com/nirholas/sketchapedia.git
```

## Verify the install

Clone the repository and run its checks to confirm everything works on your machine:

```bash
git clone https://github.com/nirholas/sketchapedia.git
cd sketchapedia
```

Available commands:

| Command | Runs |
|---|---|
| `npm run build` | `turbo run build` |
| `npm run dev` | `turbo run dev` |
| `npm run test` | `turbo run test` |
| `npm run lint` | `biome check .` |
| `npm run typecheck` | `turbo run typecheck` |
